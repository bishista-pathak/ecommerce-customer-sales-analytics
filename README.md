# E-Commerce Customer & Sales Analytics

## Project Overview
This project analyzes historical transaction data from a UK-based online retailer to understand sales performance, customer purchasing behavior, product performance, and geographic trends. The analysis uses data analytics and machine learning techniques to identify valuable customer segments and generate actionable business recommendations. The project aims to demonstrate an end-to-end business analytics workflow, from data preparation and exploratory analysis to customer segmentation, predictive modeling, and business intelligence visualization.
